One timetable, three networks

To analyse a timetable as a network, you first have to decide what counts as an edge. Lamanna, Prisma and Medeossi give three answers. In the stations view, an edge joins neighbouring stations on a train's path, including stations it runs through. In the stops view, it joins consecutive stops only. In the changes view, it joins every pair of stations you can travel between without changing trains.

Each view answers a different question. The stations view shows where trains run, the stops view where they serve, and the changes view where you can get to directly. Cluster each one (the paper uses Infomap) and you see which stations the timetable binds together. The paper uses this, with a Timetable Connectivity Index, to compare Norway's 2024 timetable with a planned 2033 one.
