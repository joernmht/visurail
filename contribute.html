Contribute a visualization

Have a rail paper with one idea that becomes clear when you can play with it? Add it.

Requirements

  • The paper is published under CC BY (any version). Name the licence and link to the landing page.
  • The visualization explains one idea of the paper and says plainly what it simplifies.
  • Code is Apache-2.0. Don't copy GPL code; re-implement the idea and link to the original.
  • It runs in the browser without a build step and uses the site's colour variables, so dark mode keeps working.

How

  1. Add an entry to assets/js/entries.js with a domain and any interfaces from assets/js/taxonomy.js.
  2. Copy one folder under viz/ to viz/<your-slug>/ and replace the toy model.
  3. Open a pull request on GitHub. Ideas without code are welcome as issues.
